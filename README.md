# 上海黄浦区 Citywalk 路线与行为分析

将非结构化社交媒体路线叙述转化为“空间节点—行为组合—传播表现”的分析框架，比较不同漫步内容的组织方式，并形成面向路线规划与体验研究的洞察。

本研究由本人主导，本仓库聚焦**上海黄浦区案例**，展示从分析框架、代码与提示词到样本处理、行为分析及图表表达的研究过程。另外两地的数据整理由合作研究者完成，本仓库不包含其数据。

> 仓库说明：代码可用明确标注的合成数据演示；分析代码、提示词与图表均由本人完成。没有公开原始帖子、用户账号、个人信息或采集凭证，暂不添加许可证。

## 研究问题

1. 如何把路线攻略中的地点和活动叙述结构化，使不同内容可以比较？
2. 黄浦区不同传播表现的Citywalk内容，在节点构成与行为组合上有哪些差异？
3. 如何把分析结果转化为路线体验设计的参考，同时避免把平台互动当成线下体验效果？

合作论文采用环境—行为系统设计视角，构建“环境—行为—体验”框架。本案例将环境落到节点类型、行为落到文本中的活动组合，传播反馈则用收藏、点赞和评论等平台指标近似表示。它们是传播表现代理变量，不是实测步行轨迹、真实满意度或因果效果。

## 数据来源与分析范围

历史数据来自小红书关键词检索和人工筛选。材料包含标题、正文、节点、发布时间以及赞藏评转等字段；原始内容与身份字段不随本仓库发布。数据覆盖期为2025-04-12至2026-04-12，共一年（作者确认）。工程文件名中的“半年内”为历史命名，不作为本案例时间窗依据；论文中的三地总量不作为上海样本量使用。

本地现有上海维度表包含196条nodes行和196条behaviors行；不是392条独立路线或用户。当前汇总版本四组数量为152、37、5、2；另有147行旧版本，不混用。原程序按笔记链接匹配得到154组；链接缺失和重复键会影响汇总覆盖。完整核对见[方法审计](docs/method-audit.md)。

## 分析流程

`UGC采集与筛选 → LLM路线节点抽取 → 节点类别编码与行为标注 → nodes/behaviors双行结构 → 时间归一指标 → KMeans分组 → 节点/行为组合分布与笔记内共现 → 模式解释与研究洞察`

路线抽取脚本虽保留规则辅助函数，当前入口实际只调用LLM。分类脚本final.py使用DeepSeek API及缓存，先分类节点，再根据路线文本为各节点输出行为代码。仓库保留[原分类提示词](docs/taxonomy.md)以说明框架，不公开含凭证的原采集器或原文缓存。

## 分类、变量与方法选择

- 节点：A道路、B文化、C商业建筑、D公共娱乐、E建筑、F历史、G风景、H住宅、I未定义、J交通；二级定义以原提示词为准。
- 行为：X游览形式（有目的/无目的）、Y交通（步行/骑行/水上/其他）、Z综合休闲（参与体验、深度体验、阅读、购物、拍照、美食、饮品、观景、户外）。多行为字符串作为组合计数。
- 日均收藏 = 收藏量/存活天数；日均点赞 = 点赞量/存活天数。基准日固定2026-04-12，存活天数至少1天。
- 互动强度 =（点赞+评论+转发）/收藏量，仅作描述；不是曝光归一后的互动率。日均值是累计量除存活时间，不是观察到的每日增长序列。

KMeans用于对数值特征作探索性分组，便于比较不同传播轮廓，不能据此自动证明行为机制。**实际脚本仅用日均收藏、日均点赞两个未缩放特征，K=4、random_state=42、n_init=10。** 论文写“三个标准化指标”，与现有工程不一致，故本案例以代码为准。不虚构肘部法、轮廓系数、显著性检验或最优K证据。

## 四类 Citywalk 模式

以下名称为论文对空间和行为特征的解释，数字Cluster来自现有工程，不能互换。

| 模式 | 工程标签与路线行数 | 上海材料中的组织特征 |
| --- | --- | --- |
| 主流漫游型 | Cluster 1，152 | 展览、饮品、地标、街巷与绿地构成复合日常体验，行为较多样 |
| 攻略工具型 | Cluster 3，37 | 交通接入、地标、公园与商业补给更突出，强调可导航与可复现 |
| 打卡传播型 | Cluster 0，5 | 地标、公园、宗教空间较集中，倾向视觉场景与拍照表达；样本小 |
| 精品策划型 | Cluster 2，2 | 公园、滨水与街巷组合突出，观景与漫步更集中；仅作个案特征观察 |

## 主要洞察

- 黄浦区内容呈现商业消费、文化展览、建筑地标与公共景观的复合组织，单靠“热门地点清单”难以解释路线体验。
- 同为Citywalk，内容可能承担不同任务：漫游探索、降低规划成本、拍照表达，或策划景观体验。路线研究可以比较这些组织方式，而不只统计节点数量。
- 节点与行为组合的对应为策划提供假设：交通与补给节点可支持路线执行，文化空间与街巷可支持探索，公园滨水可支持观景停留。但本研究没有验证这些安排能显著提升满意度或传播效果。
- 平台高互动的小样本不能直接代表大众偏好；“精品策划”是解释性命名，不是经过实验验证的质量等级。

## 运行与复现

保留原始材料，发布代码由现有analysis.py适配而来：只把Excel输入/输出改为匿名CSV、把匹配键改为route_id。聚类特征、缺失填0、固定K与原有共现逻辑保留，没有反向编造研究管线。

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python src/analyze_routes.py --input data/synthetic/routes.csv --output reports/generated
```

默认合成数据为8条虚构路线、16行。**它只演示程序，不代表黄浦区真实结论，也不能用来复现真实样本数量或四类比例。** 输出6个CSV汇总。运行不需要模型Key、不采集数据、不调用外部API。

私下用原数据副本重跑原脚本：196条nodes行、四组数量一致，聚类分配调整兰德指数ARI=1；节点和行为分布最大百分比误差约3.1e-14。表格排序、浮点数或格式可能不同，不能称为文件字节完全复现。详情见[复现报告](reports/reproduction.md)。真实数据未提供，所以公开仓库只能复现程序流程，无法独立重跑真实研究结果。

## 局限

单平台样本受到发布动机、用户构成、推荐机制、季节与筛选策略影响；互动代理不能代替线下体验。存在小样本聚类、数值缺失、固定K与缺乏尺度敏感性验证的问题；分类受模型版本和提示词影响，未提供编码准确率。笔记内笛卡尔积共现不是节点级行为验证。未提供实地观察、GPS、访谈或对照实验来验证解释。时间窗已按作者确认统一为一年；论文3指标叙述与现有2特征实现的差异，以及旧新样本版本的区别仍予以保留。
