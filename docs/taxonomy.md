# 原工程分类体系与提示词

摘自final.py中的分类定义；不是本次新建的分类体系。节点A–J共10个一级类别、38个含I兜底的编码；行为X/Y/Z共15个编码。以实际提示词为准，原提示词中的分类文字可能与论文概括略有差异。

## 节点提示词

```text

请根据以下分类体系，将上海城市漫步路线中的“节点名称”归类到最合适的字母编号（如 A1, B2, C4 等）。

分类体系：
A-道路
  A1-小巷（街道/胡同/巷道）
  A2-普通道路
  A3-人行道（绿道/木板路/走廊）
B-文化类型
  B1-文学展览空间（艺术画廊/展览厅/博物馆[科学博物馆/纪念馆]/图书馆）
  B2-宗教场所（寺庙/道教寺庙/教堂/神社）
  B3-学校/研究机构
  B4-公园（文化和创意公园/工业公园）
  B5-文化艺术中心（艺术中心/艺术区/文化中心）
  B6-体育设施（体育馆/奥林匹克体育中心）
C-商业建筑
  C1-餐厅
  C2-饮料店（咖啡馆/茶馆/酒吧）
  C3-食品零售店（小吃店/甜点店/馒头店）
  C4-购物中心（购物中心/商场/商业中心）
  C5-市场（早市/夜市/蔬菜市场/花卉鸟类市场）
  C6-书店/学院/图书城
  C7-其他零售店（百货商店/服装店/珠宝店/文化创意商店/摄影工作室/玩具店）
  C8-综合综合/房地产项目
  C9-娱乐和体育设施（剧院/剧场/电影院/音乐厅）
  C10-商业用地
  C11-酒店/度假村
D-公共娱乐类型
  D1-公园和绿地（花园/公园/生态公园/植物园/动物园/游乐园）
  D2-广场
E-建筑
  E1-古代建筑（宫殿/古代住宅/古城门墙/古塔/古桥/亭子）
  E2-地标（电视塔/摩天大楼/桥梁/摩天轮）
  E3-现代和当代建筑及建筑群
  E4-革命纪念馆（纪念碑/纪念塔/堡）
F-历史
  F1-故居
  F2-古城/古镇/古村/革命遗址
  F3-以前的住所
G-风景
  G1-景点/旅游区
  G2-自然景观（山/河/湖/海/溪/泉/池/海湾/崖/洞穴/草地/山谷）
  G3-海滨（海岸/海滩/河边小径/岛屿）
H-住宅建筑
  H1-邻里
  H2-乡村/城镇/城市地区
  H3-住宅区（旧住宅区/社区）
  H4-住宅（公寓/别墅/豪宅）
I-特别的（未定义）
J-运输
  J1-汽车站/地铁站/机场/码头/港口/渡轮码头

节点名称："{node_name}"
只输出字母编号，不要输出任何解释。例如：C4

```

## 行为提示词

```text

请根据以下行为分类体系，分析一段上海城市漫步笔记内容，并为每个节点标注其对应的行为。

行为分类体系：
X-游览形式
  X1-有目的（参观/打卡/逛菜市场等具体地点）
  X2-无目的（逛吃/逛街/闲逛/发呆/散心）
Y-交通方式
  Y1-散步（散步/漫步/步行）
  Y2-骑行（骑行）
  Y3-水上交通（划船/游船/坐船/坐摇橹船/坐轮渡/水上巴士）
  Y4-其他通行（其他交通方式）
Z-综合休闲
  Z1-参与式体验（手工/手作/抄经/汉服体验/非遗体验/写明信片/胶片冲洗/撸猫/喂猫）
  Z2-深度体验（观赏文化表演/听评弹/听曲/看展）
  Z3-阅读（看书/阅读）
  Z4-购物（购物）
  Z5-拍照（拍照）
  Z6-吃美食（品尝美食）
  Z7-喝饮品（喝咖啡/下午茶）
  Z8-观赏风景（赏花/看夜景/赏灯/看日落/登高/远眺）
  Z9-户外/自然类（喂鸽子/露营/野餐/钓鱼）

笔记内容：
{content}

路线节点列表（按顺序）：
{node_list}

请为每个节点标注行为代码（多个代码用英文逗号分隔，如 "Z4,Z5"）。如果该节点在笔记中没有提及任何行为，输出 "/"。
请输出 JSON 格式，键为节点名称（保留原始字符串），值为行为代码字符串。例如：
{{
  "K11购物艺术中心": "Z4",
  "新天地广场": "Z6",
  "新天地北里": "Z5"
}}

只输出 JSON，不要其他内容。

```

行为输出中“X1,Z5,Z8”在现有统计里作为一个完整组合字符串计数，不是拆成三个独立行为后计数；“/”表示未提及行为，也进入原统计分母。
